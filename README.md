🎯 TikTok Content Hub
An internal marketing tool that helps discover high-performing financial content on TikTok and turns it into useful insights for the content team.

Overview
The tool searches TikTok for relevant financial videos, filters for the top performers, and uses AI to analyse each one — helping the marketing team quickly find trending, relevant content ideas for an expat audience.

--Built With--
Node.js — application logic
Vercel — hosting
ScrapeCreators API — TikTok content data
OpenRouter — AI processing (transcription + analysis)
ffmpeg — audio processing
